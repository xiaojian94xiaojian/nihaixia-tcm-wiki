# 倪海厦中医知识库

基于倪海厦（汉唐中医）**人纪系列**课程的经方中医知识库，按 LLM Wiki 方法论构建，封装为 Claude Code Skill，开箱即用。

## 内容概览

本知识库收录倪海厦人纪五大经典的全部教学内容：

| 经典 | 内容 | 形态 |
|------|------|------|
| 针灸大成 | 十二经络、奇经八脉、针灸治症 | 视频同步文稿 |
| 黄帝内经 | 前言 + 81 篇 + 至真要大论 | 视频同步文稿 |
| 神农本草经 | 上中下三经 357 味药 | 同步文稿 + 注解本 |
| 伤寒论 | 六经辨证全篇 | 同步文稿 + 注解本 |
| 金匮要略 | 23 篇杂病 | 同步文稿 + 注解本 |

还包含：
- **医案**：2005-2006 年倪海厦先生临床医案记录
- **文章集**：汉唐中医经典文章、癌症医案、中西医观点
- **访谈**：梁冬对话倪海厦七讲合集

## 知识库结构

```
nihaixia-tcm-wiki/
├── SKILL.md           # Skill 入口（协议 + 路由 + 约束）
├── SCHEMA.md          # Wiki Schema 规则
├── raw/               # 原始资料层（只读，12 个文件，~13 MB）
├── wiki/              # 知识库层（179 个页面）
│   ├── agent/         #   Agent 协议（回答、路由、检索、自进化）
│   ├── 概念/          #   13 个核心概念（经方、六经辨证、阴实等）
│   ├── 专题/          #    7 个综合专题（学习路径、癌症叙事等）
│   ├── 来源/          #  136 个来源摘要 + 7 个领域子索引
│   ├── 对比/          #    3 个版本对比（伤寒/金匮/本草）
│   └── 实体/          #    1 个实体页（倪海厦）
└── derived/           # 派生切片层（321 个章节切片）
```

## 使用

在 Claude Code 中输入 `/nihaixia-tcm-wiki` 激活 Skill，然后直接提问：

```text
/nihaixia-tcm-wiki 什么是六经辨证？
/nihaixia-tcm-wiki 大青龙汤和小青龙汤的区别是什么？
/nihaixia-tcm-wiki 倪海厦怎么说乳癌的病机？
/nihaixia-tcm-wiki 请帮我规划一个经方学习路径
/nihaixia-tcm-wiki 足三里穴在什么位置？有什么功效？
/nihaixia-tcm-wiki 桂枝汤的组成和适应证是什么？
```

Skill 激活后会按以下流程工作：

1. 读取 `SKILL.md` → `SCHEMA.md` → `wiki/agent/` 协议
2. 用 `wiki/agent/术语索引`（150+ 术语）和领域子索引定位
3. 读取 `raw/` 原始资料核验事实
4. 以「资料原意 + 综合标注 + 医学边界」三要素输出回答

## 设计原则

| 原则 | 说明 |
|------|------|
| **Wiki 是导航，raw 是依据** | 所有事实回答必须回到原始资料核对 |
| **推理必须隔离标注** | 模型推理标注 `[Agent 综合]`，不得伪装成资料原文 |
| **医学边界不可省略** | 所有疾病/方药相关回答必须声明「不替代医生诊疗」 |
| **自下而上创建** | 概念/专题页需 ≥2 个不同来源支撑才创建 |
| **宁缺毋滥** | 宁可不写，不可写错；宁可漏掉，不可让推理伪装成资料 |
