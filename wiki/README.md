# wiki

这里是 AI 维护的知识库层。

## 入口文件

- `index.md`：内容索引，按来源、实体、概念、对比分组。
- `log.md`：操作日志，只追加，不重写历史。
- `agent/回答协议.md`：Agent 回答中医问题时的口径、推断标注和医学边界。
- `agent/问题路由.md`：Agent 按问题类型选择专题页、概念页和来源页的路由表。

## 页面目录

- `agent/`：Agent 专用的回答协议、问题路由、术语索引和覆盖报告。
- `来源/`：每篇原始资料的摘要页。
- `实体/`：人、公司、产品、工具等实体页。
- `概念/`：原理、方法论、技术术语页。
- `专题/`：跨来源综合页，优先服务 Agent 回答问题。
- `对比/`：跨来源横向综合分析页。

## 维护规则

详细规则见根目录 `SCHEMA.md`。这里的知识页面由 Codex 或 Claude 维护，用户主要阅读和校对。
