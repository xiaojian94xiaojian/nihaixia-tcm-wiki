# 覆盖报告

本页记录当前知识库对 Agent 回答问题的覆盖状态。

## 覆盖较充分

- 人纪五大经典：已有针灸、伤寒、金匮、黄帝内经、神农本草经及注解资料。
- 经方学习路径：已有课程文稿、注解本和梁冬访谈。
- 六经辨证：已有《伤寒论》同步文稿、注解本和访谈讲解。
- 医案与癌症叙事：已有《倪海厦先生医案》和《汉唐中医经典文章医案集》。
- 倪氏健康标准：已有访谈和医案多处支撑。
- 中医科学观与科技观：已有梁冬访谈和文章集材料。
- 概念层：已建立 13 个核心概念页（经方、六经辨证、阴实、阴阳、营卫、气化、五行生克、三焦、八纲、四诊、治未病、方证、脏腑），覆盖基础理论、辨证框架和诊断方法。
- 术语索引：已扩展至 150+ 条术语，覆盖方剂、药物、穴位、病证、基础理论和学习路径，支持 O(1) 精准检索。
- 领域子索引：已建立 7 个领域子索引（伤寒、金匮、本草、针灸、内经、医案、访谈文章），Agent 可按领域直达来源页，不再需要扫描全表。
- 方剂/药物/穴位检索：术语索引 + 领域子索引已覆盖高频方剂速查（伤寒 31 方 + 金匮 42 方）、药物速查（28 药）、穴位速查（20 穴）、病种速查（13 病种）。
- 专题预设问答：7 个专题页均已补充 3-5 个高频问答对，常见问题可一步到位。
- 版本对比入口：已建立伤寒论、金匮要略、神农本草经同步文稿与注解本的 3 个对比页。
- Agent 检索协议：已建立检索决策和健康检查入口，支持回答前判断范围、证据强度、回源要求和知识缺口。

## 覆盖中等

- 方剂/药物/穴位专题页：术语索引和领域子索引已解决检索定位问题，但尚未建立独立的方剂专题页或单味药专题页（可按需要后续创建）。
- 轻量关系图谱：概念页和专题页已有基本互链，但上位概念、相关病机、相关方剂、回源入口等固定区块的覆盖因页面而异，部分页面仍需补全。
- 针灸治症专题：已有针灸来源页和领域子索引，但治症专题化程度仍低于伤寒/金匮/本草。

## 覆盖较弱

- 与现代医学指南的对照：当前知识库主要记录资料观点，不维护现代医学指南。
- 现代临床安全边界：仅能做一般提醒，不能替代医生判断。
- 非倪海厦体系的中医观点：当前资料高度集中于倪海厦和人纪体系。
- 跨领域综合：当前库只适合作为中医领域 brain，不宜直接承载 AI、投资、管理等其他领域资料。

## 回答建议

- 问倪海厦体系内的问题，可以资料为主、适度综合。
- 问现代医学、现实诊疗、用药剂量和病情判断时，应明显降低确定性，并提示需要医生诊疗。
- 问非倪海厦体系观点时，要说明当前知识库覆盖不足。
- 回答复杂问题时，按 [[wiki/agent/检索决策]] 增加“知识缺口”说明。
- 做健康检查时，按 [[wiki/agent/健康检查]] 记录索引、回源、路由、概念覆盖和医学边界状态。
