# 问题路由

本页用于帮助 Agent 在回答前快速选择应读取的页面。

## 通用流程

1. 先判断用户问题属于哪类。
2. 读取 [[wiki/agent/检索决策]]，确认是否需要精确匹配、关系扩展或 raw 回源。
3. 先读对应概念页、专题页或对比页。
4. 再读来源页补证据。
5. 需要精确事实、原话、方药或病例细节时回到 raw 原文。
6. 回答时遵守 [[wiki/agent/回答协议]]。

## 无匹配时

如果路由表没有覆盖用户问题：

- 先读 [[wiki/agent/检索决策]]，再搜索 `wiki/index.md` 和 `wiki/来源/`。
- 若仍找不到，说明当前知识库覆盖不足。
- 可以给出脱离知识库的推理，但必须按 [[wiki/agent/回答协议]] 标注。
