# 自进化协议

本页规定 Agent 在回答后如何判断是否将答案沉淀为知识库内容。核心约束：**宁可不写，不可写错；宁可漏掉，不可让推理伪装成资料。**

## 铁律

以下规则不可被 Agent 自身判断覆盖：

1. **回源可追**：任何写入条文必须能追溯到至少一个具体 raw/ 原文或来源页。写出时必须附来源链接。
2. **推理隔离**：Agent 的综合、推断、补充必须显式标注 `[Agent 综合]`，不得以资料原文口气写入。
3. **零冲突**：拟写入内容不得与已有来源页或概念页的明确表述矛盾。如有疑似冲突，写入前必须先标记为争议。
4. **不可降级**：Tier-3（高风险）写入不得降级为 Tier-1（自动）写入。Agent 对自己的评估可以调用但不能越权。

## 权限分级

### Tier 1 — Agent 可自主写入（无需用户确认）

触发条件（必须同时满足）：
- 仅在**组织已有内容**，不产生新结论
- 写入内容**直接从已有 Wiki 页面或 raw 原文摘录**，不加综合

操作范围：

| 操作 | 条件 | 上限 |
|------|------|------|
| 术语索引追加 | 回答中出现了一个术语索引里没有的术语，且该术语在 ≥1 个来源页中有明确位置 | 每次 ≤3 条 |
| 专题页 Q&A 追加 | 答案完全来自已有专题页覆盖范围，且 Q&A 对是已有内容的 1:1 改写 | 每次 ≤2 条 |
| 子索引速查表追加 | 只在已有速查表中补行（如方剂聚合速查补一个漏列的方） | 每次 ≤3 行 |

写入后必须在回答末尾告知用户（一行提示即可）。

### Tier 2 — Agent 提议、用户确认后写入

触发条件（必须同时满足）：
- 回答涉及 ≥2 个来源或来源页
- 内容不是已有 Wiki 页面的简单重复
- 不存在与已有资料的冲突

操作范围：

| 操作 | 条件 | 限制 |
|------|------|------|
| 新建 Q&A（无现有专题页匹配） | ≥2 来源支撑 | 先判断应追加到哪个已有专题页 |
| 概念页补充（关系区块） | 补充内容来自 ≥2 来源页 | 写入格式：`[[来源页名]] 中说明 X` |
| 覆盖报告更新 | 回答暴露了覆盖报告未记录的缺口 | 只能记录缺口，不能自行更改覆盖等级 |
| 来源页「后续专题候选」追加 | 发现值得建的专题方向 | 只加候选，不自动创建 |

Agent 主动提案，用户 confirm 后执行。Agent 不得替用户做确认。

### Tier 3 — Agent 提议、用户确认、来源审计后写入

触发条件（必须同时满足）：
- 满足 SCHEMA.md 的「≥2 篇不同来源」规则（同一长资料内部多次出现 ≠ 多来源）
- 内容跨至少 2 个资料族（如伤寒 + 金匮 + 访谈，而非同一本书的两个篇章）
- 该主题已被问到 ≥2 次，或同一资料模式在所有 7 个领域子索引中都有体现

操作范围：

| 操作 | 额外条件 |
|------|----------|
| 新建概念页 | 必须确认在 ≥2 个资料族中出现。写时注明每个来源的具体位置。 |
| 新建专题页 | 必须有 ≥3 个跨来源支撑。Agent 综合部分必须用 `[Agent 综合]` 标记。 |
| 新建对比页 | 必须确认两方来源都能独立支撑各自立场。 |

来源审计 = Agent 在提案中列出每个支撑来源的具体引用位置（raw 文件名 + 行号范围，或来源页 + 具体段落）。

## 防偏移检查（每次写入前必须过）

Agent 在提议任何写入前，必须回答以下 4 个问题（回答中应显式出现）：

```
1. 这条内容来自哪个 raw/ 原文或已有来源页？（给出具体位置，不可模糊）
2. 写入版本是否加了资料中没有的结论？（是 → Tier 3，且必须标注 [Agent 综合]）
3. 是否与已有来源页/概念页的明确表述矛盾？（是 → 不写入，先标记争议）
4. 这条内容会改变用户对某专题/概念的已有印象吗？（是 → 至少 Tier 2，用户确认）
```

4 个问题中任何一个答案为「无法确认」→ 不写入，记录到覆盖报告的待查缺口。

## 冲突与撤回

- 如果后续发现已写入内容与 raw 原文矛盾 → 立即在写入页标注 `[待核对：可能与原文冲突]`，不直接删除。
- 如果用户指出写入内容脱离资料 → 撤回写入，追加到 log。
- 写入内容的 `tags` 中应包含 `自进化` 标签，便于追溯和撤回。

## 进化不越界

以下操作**永远不允许**：
- 修改 raw/ 中的任何文件
- 修改已有来源页的「资料中的主要表述」区块（只能追加「后续专题候选」）
- 把 Agent 推理改写为资料原文语气
- 在没有新 raw 资料的情况下创建实体页
- 单次回答后自动创建 Tier 3 页面（必须跨多次问答积累）
