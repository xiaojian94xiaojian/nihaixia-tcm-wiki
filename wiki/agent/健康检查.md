# 健康检查

本页规定本知识库的常规检查项。目标是让知识库长期保持可检索、可回源、可综合，而不是只堆来源摘要。

## 检查目标

- 入口清晰：Agent 能从问题路由进入正确页面。
- 证据可追：综合页能回到来源页，来源页能回到 raw 原文。
- 关系可走：概念、专题、对比之间有明确连接。
- 缺口可见：资料不足、覆盖薄弱和过度推理要被记录。
- 边界清楚：医学相关内容必须保留资料观点和诊疗免责声明。

## 固定检查项

| 检查项 | 通过标准 | 常见处理 |
|--------|----------|----------|
| 索引一致性 | `wiki/index.md` Stats 与实际页面数量一致 | 更新 Stats 和表格 |
| Agent 入口 | `回答协议`、`问题路由`、`术语索引`、`检索决策`、`覆盖报告`、`健康检查` 均在索引中 | 补索引 |
| 高频术语 | 高频术语已有概念页，或在覆盖报告中标为待建 | 新建/更新概念页或记录缺口 |
| 来源沉淀 | 新来源进入来源页后，关键概念能回流到概念/专题候选 | 更新覆盖报告或专题候选 |
| 回源链路 | 专题/概念/对比页能指向来源页，必要时指向 raw | 补资料依据和回源入口 |
| 关系线索 | 概念页和专题页有相关概念、适用问题或回答边界 | 补轻量关系区块 |
| 矛盾观点 | 不同来源冲突时有标注，不强行合并 | 建对比页或在专题页注明 |
| 医学边界 | 诊疗、方药、针灸内容有免责声明 | 补边界提醒 |

## 健康分级

| 等级 | 含义 |
|------|------|
| A | 路由清楚、来源充分、回源完整、缺口已标注 |
| B | 可回答常见问题，但部分概念/专题仍需补关系或来源 |
| C | 来源存在但综合层薄弱，Agent 需要大量临时搜索 |
| D | 索引、路由或回源链路明显失效 |

## 建议频率

- 每次新增资料后，执行一次轻量检查：索引、路由、覆盖报告。
- 每新增 5-10 份资料后，执行一次中等检查：高频术语、专题候选、概念候选。
- 每次用户说“健康检查”时，按本页完整检查并追加 [[wiki/log]]。

## 输出格式

健康检查结果建议使用：

```text
健康等级：

发现的问题：
- ...

已修复：
- ...

建议后续：
- ...
```
