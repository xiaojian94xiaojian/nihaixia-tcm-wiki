# 大柴胡汤症

09/05/2006，女，1968年生，于 1984年得到淋巴癌，当时是十六岁，无做任何治疗，之后结婚育有四子女，其在怀孕之前得到甲状腺亢进问题， 服用放射性碘 125，照理说服用此药后的副作用就是不孕，但是她却很奇蹟的连生四个小孩，连她的医师都无法了解为何她是例外。

今天来诊是因为倦怠无力，又便秘，时常一週都没有大便，小便深黄，时常呕心，不排气，吃完饭后就腹胀，身体自己感觉外面很热，裡面很冷，脉诊是弦数有力之脉，舌苔黄乾，这在经方家一看就知道是大柴胡汤症无疑。但是这阶段对西医而言，还是很正常的，还是没有病的。但是由于病人的警觉，所以我们中医就可以在只有症状的阶段，就将它治好，而大柴胡汤症是介于少阳与阳明之间的病症，此阶段无死症，如果失治，将来进入厥阴的阴实后，就是肝癌或是大肠癌了。

上段红字部份就是大柴胡汤的主要症状，然而没有加大黄与芒硝就不是大柴胡汤，温病家一提到大黄与芒硝时，就脸色大变，吓到手软而不敢使用，这大柴胡汤症是介于少阳与阳明之间的病症，同学们只要对于六经辨症的理论很了解时，只要问一下病人一些问题，就可以知道如何使用经方，此人处方如下:

柴胡 三钱 黄芩 三钱 半夏 四钱 枳实 三钱 白芍 五钱 大黄三钱 芒硝二钱(平分成二包)冲服，生薑 二片，大枣十枚， 除芒硝不煮外，其他用水六碗，煮成二碗，早晚餐前各一碗，服用前将汤加热后，再将生芒硝直接冲入汤中即可。

这种一剂就知的就是经方，我心知病人只需喝完第一碗汤剂后，就立刻知道进步多少了。如果人人都在这种阶段就找中医治疗，将身体调理到正常阶段，怎麽会有人得到癌症呢? 所谓上工治未病，就是指这裡了。

此女孩有严重的头痛，经过问诊，她告诉我她的头痛是从眼睛四周开始痛，然后沿着膀胱经向后脑方向直下到肩膀位置，几乎是每天痛，而且现在跟我讲话时都正在 痛，我ㄧ听这是针灸的好时机，于是我针下后溪，申脉，双眉陵穴(阴陵泉下一吋之奇穴)。最后加一针百会，针下后头痛即帐然若失。这就是立竿见影的传统针 术，没什大不了的，我人纪班学员当人人都可以做到的，因为这只需要初级中医程度即可做到。之所以如此选穴，因为病情是在督脉与阳蹻脉上，其看似膀胱经，实则不然。

小承气汤症

初诊 : 09/06/2006， 女，46 岁，自述从生完第二胎至今，大便非常困难，每天早上都得坐在马桶上等很久，然后大便才姗姗来迟。

问诊 : 病人时排气多，小便色中黄，身热，口渴，双脚热。

脉诊 : 脉洪大有力。

望诊 : 面色赤，声大且急，舌苔黄乾。

诊断 : 小承气汤症。

处方 : 小承气汤胶囊。

说明 : 小承气汤是专门使用在大便堵在小肠中时用的，主要症状就是排气多，大便出来很慢。

经方家在使用经方时，因为很了解处方跟症状相合时，都是一剂就知，因此立方是药简力专，小承气汤只有三味药，但是因为对症，所以病人必然恢复很快，综观此人已病数年，却无医可以帮她，这是因为经方是唯一可以治疗她的处方，其他医师怎会使用小承气汤呢?因此才会一托再拖，一直不好，直到今日她遇到我，我开的就是唯一处方，非此不治，我不用看覆诊就可以知道她必然会恢复过来了。

四逆汤症

09/04/2006，女，肾脏衰竭，35岁，其有西医所谓多发性囊肿，因此而造成肾脏衰竭。

病人自述，早起时头昏，胃口平平，睡不深，身体觉冷，四肢也冷，手时常冒冷汗，口渴喜温饮，倦怠无力，夜尿频数，小便次数多而量少，仍有小便意愿，右腰时觉肿胀且痛。

麻黄附子细辛汤症

初诊 : 女，1959 年生，月经有六个月没来，失眠，乳头极痛，后项痛，下背痛，双脚指尖痛且冷， 过重，想减肥。

问诊 : 睡眠品质差，大便时好时坏，小便中黄，下背痛在第十五，六椎处，后项痛在手太阳经上，体力很差，白天无精打採，胃口很强，手脚冰冷。

脉诊 : 细小无力，, 沉， 属于少阴症。

诊断 : 脉细无力，白天疲劳，无体力， 从此二症就可以得知，病人是得到少阴症， 其他症状只是附带的，并非主要症状，经方讲究的是同症同治，因此给于麻黄附子细辛汤，方中的麻黄对一般中医与西医来说是提神药物，所以如果病人有失眠 时，,都不会给病人服用的，但是只要症状相同，我们就用它，不必顾忌，我已经使用麻黄治疗过许多得到失眠的病人，这些人反而因为吃了麻黄后睡眠品质因而恢 复，所以不用担心使用麻黄。

下背痛在督脉上肩痛在手太阳经上，针灸就可以了，我选用后溪，申脉，委中，腰腿点奇穴，至于脚指尖痛，这是附子症，病人服下汤剂后就会好转的，不需要针灸。

问诊 : 小便色澹白，虽有便秘却无多少腹痛，也无便意，上身燥热难当，,下身却很冷，口不渴，睡失眠。

这种病例非常明显的是属于大黄附子细辛汤症，这处方是唯一可以治她的处方，就是因为是唯一，无可取代的处方，所以她在遇到我之前从未被治好过，因为这是经方，第一 : 苏联与美国西医当然是从未听过有这处方.因为他们没有文化，又自以为是天下无敌，瞧不起中医，所以他们从未学过中医，因此病人失治. 第二 : 几乎所有中医都是温病派或是学院派，因此他们一看到有大黄，有附子，有细辛时，立刻跳过去，不但不读它，也不想用它，只是因为自己不懂，所以不用，而因此也造成病人失治，这就是她一直没有好的原因。

这种一剂就知的处方是唯一可以治疗她的处方，无可取代，而世上有多少人得到跟她相同问题的人存在，你们说呢? 这些病人通通无治，只因为医师学艺不精造成，处方早就存在于我国至少二千年以上，结果却无人会用，药方既简单又便宜好用，人纪学员们请记住这使用的时机，我将在教伤寒时会详加再说明的。

有下利的大承气汤症

09/07/2006，男，42 岁，美国白人，我的忠实病号，此人只要身体一出问题，第一个就想到我，今天来诊症状很特殊，记录如下 :

自述 : 一日数次下利，时常来不及跑到厕所，已经三天了，今天他同时介绍一位女病患就是前面吃大承气汤的那位小姐。

问诊 : 口渴，喜冷饮，肚痛，睡不好，反覆不定，燥热，下水利，不见成型大便。

触诊 : 用手指压他的天枢穴，表现拒按。

处方 : 厚朴 二钱 枳实 二钱 大黄 三钱 芒硝二钱分二包冲服。给五付药。

这种因为乾燥大便阻塞在大肠中，而造成大便无法排出，只有水可以通过肠道的便秘，让许多中医师无法了解这种是因为便秘而引起的下利问题，从而无法想像是大 承气汤症，因而给于止利药，于是造成病人更下利，这种桉例也是常见的一种大承气汤症。用大承气汤将燥矢攻下来，于是下利自然就好了，这就是一剂就知的唯一 处方，如果遇到温病派中医就不是如此治了，倒楣的是病人。

我将于解说伤寒论时，替大家分析如何正确使用大承气汤。

在临床跟诊之前， 请大家务必都熟悉人纪系列的五部曲，因为你们跟我真正临床时就会了解到，我看任何一位病人，同时会用到这五套人纪系列，我每天的病人很多，而每个病人都不 一样，加上我解说的速度必须快，因为看完这位还有下位在等着，每天你都会学到新的病情解说，从针刺选穴法，如何开立处方，如何用内经与六经辨症法来分析病 情，经方的成方与複方如何搭配使用，经方处方的增减，如何选择单味药物等等，到时大家可能用手写记录都来不及，所以如果你们都很熟悉于人纪系列时，就可以 跟得上进度，我就不需要重複讲解，每天面对的每一位连我都尚未看过的新病人时，都是一个挑战，都充满着一个未知，希望大家都能从跟诊经验中获得我的治病经 验，预祝有志成为一位经方家的所有学员们都可以心想事成，都能成为一位真正的经方名家。青出于蓝，要更胜于蓝，我不过是一名全力发扬经方的中医师，称不上是国手级的中医，但是我很希望我的学生中将来能够出现国手级的中医，很感谢大家对于经方的支持与信心，我能做到的就是这麽多了。

目前已经有二位来自加州的李医师跟颜医师正在跟诊中，等到上金匮时，他们将跟随我返回台湾一起参加人纪的最后课堂训练课程，到时有意来美跟诊的同学们，可以利用课馀时间向他们询问一些有关住宿与生活上的问题，他们将跟着我做实际临床一段时间，所以到时他们最清楚这些问题，暑假大家就会跟他们碰到面。

请大家不要打扰我写地纪， 让我一气呵成的完成它，明年开始我将会减少门诊量，约一半时间在美国，一半时间在大陆，我要替我中华文化的复兴，尽一己之力，地纪中不单只是包含有中医 学，只要有关于我国传统文化的，都会蕴藏在内，尤其近来中国政府有意将简体化中文，完全取代繁体中文，我虽为一小民，但是对于此举有许多地方见解是跟这政 策不同的，要如何说服中国政府改变这个政策呢？这也将利用地纪来说明繁体中文的优点在哪裡，我想是因为执政者不了解一点，就是文字本身不单单只是用做记载，语言，说明等等，真正我国使用千年以上的繁体中文早就已经超越过文字本身所需要具备的功能了，繁体中文到底有多美？有多传神？在此很难解释得出来。而简体文仅仅具有文字的形而已，无法比上繁体字的神韵，因为一时无法说明得很传神，我也将利用地纪裡的故事，来说明我国文字之美在何处？所以地纪的工作是很重要的，我只有一个小小愿望，就是希望所有看过地纪的人，都能深深的感受到，身为一个中国人是幸运的，是荣耀的。

汉唐中医 倪海厦谨记于06/10/2007佛罗里达州自家书房

# 临床须知

1. 同学们来此目的是要学习实际临床经验，不是来讨论各人之间的是非，如果被发现到有同学不专注于学习，喜欢搬弄是非者，必将开除，列入永不受欢迎之列。

2. 诊所时常需要协助，不一定是固定什麽事情，到时要求同学帮忙时，希望大家一起协助完成。

3. 临床时，我不收取额外临床实习费用，以减轻大家的负担。

4. 无病人时，请同学在门诊处看书，不可以打扰老师休息，员工例外。

5. 跟诊时，未经老师同意，请勿发言，不可随便嬉笑，以免造成病人误解。

6. 临床跟诊实习时间与诊所同步，希望不要迟到早退。

7. 同学之间要互相帮助，如果出现小团体，排挤他人的情形时，老师将依照当时情形做定夺，一旦做出处置后，必须无条件的离开此处。

8. 过去有被老师驱逐出师门的学生在外开业中，希望同学们不要与他们来往，一旦被老师发现后，必将立刻列入不欢迎人物，逐出门牆，永不录用。

9. 每位同学都需要写跟诊报告心得，并请大家都准备一本笔记本，纪录每一临床医桉，当老师有空时，将开医疗会议，替大家解说各人遇到的医学问题，务必让大家都很明确的瞭解每位病人的治疗过程。

10. 所有来学习临床的学员们必须要瞭解，一但被老师禁止继续跟诊时，必须立刻无任何理由离开诊所，老师也将不说明为何不让你继续跟诊的理由，只要记住来此唯一目的是学习中医学，就必然受到欢迎。

11. 所有购买DVD学员请注意，你们必须先跟我台湾助理联络，我们需要先审核你的资格，经过我们同意后再来佛州诊所，凡是未经过我们事先核可而自行前来想学习临床的同学们，将不被接受跟诊，请自行离开。

12. 本跟诊须知将随时更新，以补不足之处，请学员们务必遵守此规则，千万不要触犯这些禁忌。

汉唐中医 倪海厦 08/19/2007
