# 第三十一篇 热论

# 第一节 伤寒基础论

黄帝问曰，今夫热病者，皆伤寒之类也。或愈或死，其死皆以六七日之间，其愈皆以十日以上者，何也？不知其解，愿闻其故。

黄帝问，现在看到的热性病，都为伤寒之属，有时痊愈有时死亡，其死期都在六七日之间，其恢复健康却在十日以上，这是为何呢？我不懂，请老师说明。

歧伯对曰，巨阳者，诸阳之属也。其脉连于风府，故为诸阳主气也。人之伤于寒也，则为病热。热虽甚不死。其两感于寒而病者，必不免于死。

歧伯回答，太阳经是诸阳经之首也，它的脉连到风府穴，所以能主诸阳经之气。人伤于外感风寒，必生热症，此热即令盛，亦不死人。但若寒邪进入阴经，使阳经与阴经皆感受风邪，如此一来，病人必死。

第263 页，讲热论篇，《黄帝内经》第三十一篇。黄帝说呢，所有的热病，“皆伤寒之类也”，有的时候好，有的会恢复，有的会死。那死的呢，大部分在六七日之间。好的比较慢，要到十日以上，为什么？也就是说，如果说你自己会痊愈的比较慢，那如果是死呢还比较快。

那岐伯就说了，所谓巨阳就是太阳，我们讲巨阳就是三阳汇、并，三阳并在一起，“诸阳之属，脉连于风府”，所有的“诸阳主气”，“人之伤于寒也，则为病热，热虽甚不死；其两感于寒而病者，必不免于死。”所以所有的热症，刚开始呢，都是最初是伤于寒。这就是温病，温病呢，就是热嘛，就开始治，他不晓得最初是伤于寒，所以《黄帝内经》一路下来讲的都是伤于寒，有伤寒以后才有温病。那他们呢，都是温病嘛，就开始治，就不会用热药，不会用热药。那两感于寒的意思就是，比如说我们一个人，如果说皮肤外面我们中医称之为表。那你表呢，伤到寒了没有治好。那这个寒呢，如果说你体格很好或者是这个没有乱喝酒啊，没有乱搞，去玩女人啊，或者什么样子……，你身体很好，然后你适当的这个保持心情平静，开心啊，不要去斤斤计较，不要有野心啊，这个时候，那你又知道调理五味，慢慢就恢复了。如果说你本身伤于寒了，可是你不知道如何去保护你自己，这个时候，寒会再往前走，它有时间的，后面会介绍多少时间。当寒进入我们身体里以后，比如说进入，有两种可能：第一个是少阳，第二个是阳明。当进入少阳的时候，它就会有机会传遍到阴，比如说太阴、少阳、厥阴。到阳明的时候停止了，最多就是发狂奔走，登高而歌，傍晚的时候去遛鸟（裸奔），（笑）弃衣而行嘛，最多就是这样子了。那进入少阳就会再生，当寒进入里面了以后，结果呢，你又受到了寒，这叫做两感于寒，这就比较危险。

# 帝曰，愿闻其状。

黄帝说，希望能更详加陈述。

歧伯曰，伤寒一日，巨阳受之。故头顶痛，腰脊强。二日阳明受之。阳明主肉，其脉侠鼻，络于目。故身热目疼而鼻干，不得卧也。三日少阳受之。少阳主胆，其脉循胁络于耳。故胸胁痛而耳聋。三阳经络，皆受其病，而未入于藏者，故可汗而已。四日太阴受之。太阴脉布胃中，络于嗌 【yì】。故腹满而嗌干。五日少阴受之。少阴脉贯肾，络于肺，系舌本。故口燥舌干而渴。六日厥阴受之。厥阴脉循阴器而络于肝。故烦满而囊缩。三阴三阳五藏六府皆受病，荣卫不行，五藏不通，则死矣。

其不两感于寒者，七日巨阳病衰，头痛少愈。八日阳明病衰，身热少愈。九日少阳病衰，耳聋微闻。十日太阴病衰，腹减如故，则思饮食。十一日少阴病衰，渴止不满，舌干已而嚏。十二日厥阴病衰，嚢纵，少腹微下，大气皆去，病日已矣。

歧伯回答道，伤寒起初之时，病在太阳经，所以会有头痛项强，腰椎强硬的症状。一旦失治，一星期后会进入阳明经，阳明主肌肉，此经脉络夹鼻两侧，进入眼目，会造成身热眼疼而鼻中干燥，无法安卧状。再过一候七日，病入少阳经，少阳司胆，其经脉顺延胁肋而络在耳中，会造成胸胁苦满而耳聋。如果只是三阳经络受病，病邪未入阴脏，可一汗而病去。如果未加施治正确，四候二十八日后，病进入太阴，太阴脾脏分布肠胃之壁，上络于咽口（食道口）会造成病人腹胀满而咽喉干燥。五候三十五日病邪会进入少阴，少阴肾脉贯穿肾脏，上络于肺，连系舌下治疗会造成病人口燥舌干而喝水不止。六候四十二日，病邪入侵厥阴，厥阴肝经顺延生殖器而上络于肝脏，会造成人情绪烦而腹满而阴囊上缩。一旦三阳三阴五脏六腑皆受病，气血无法运行，五脏代谢物无法排出，此人必死。

其间有不同时受寒于阴与阳者，如一候七日，病邪仍留太阳不傳里，此病邪必衰，头痛渐减而自愈。如一候十四日，病在阳明不传里，则病邪必衰微，病人身热必减而自愈。三候二十一日，病邪居少阳不传里，其病势必衰，耳中必渐可听闻。四候病在太阴，不见阳症，其邪又不傳里，其病必自衰微，腹满日减，而饮食、胃口大开。五候病在少阴，不见阳症，又不再傳里，病邪必衰，病人必渴止且腹不满矣，舌渐润而有喷嚏出也。六候病在厥阴，若无阳症，只有阴症，其病必自微弱，阴囊松下，少腹软柔，病气巳去，待日可复矣。

第 264 页，黄帝就问啊，你再详细的解说一下，让他解说一下。这一段就是整个《伤寒论》的基础、原则、理论就来自这里。这岐伯说，“伤寒一日”，这里的一日……，因为中国的文字，它有时候，令和一日，他的定义都不一样。我们这里讲的一日，应该是六天，因为我们传遍是五，一二三四五，到第五天的时候，节气会换，我们人体会换，到第六天会改变。伤寒一个周期呢应该是六天。刚开始是太阳受之，所以足太阳膀胱经一路从头面一直到背后一直到后腿去，所以“头顶痛”，腰脊会比较强硬，因为寒在里面。太阳呢，又有一个名称我们称之为寒水，为什么叫做寒水呢？你摸皮肤，背上都冰的，冰的是对的喔！你摸到热的、滚烫的，第一个太阳晒太多了，第二个你发烧了，冰的才是对的。所以当你一流汗的时候，你一摸整个汗出来是冰的，太阳是寒水。那本身是寒水，他水是冷的，所以才会保护我们自己嘛，外面跟环境有一个绝缘的东西，否则的话，没有这个绝缘的东西，我们身体不能马上随着环境改变，就没有办法去适应它。那你已经是寒水了，正常是有一点寒水在里面，那你再感于寒就是，就会造成像冰块一样——很硬，造成项强。

# 帝曰，治之奈何？

黄帝问，治法如何呢？

歧伯曰，治之各通其藏脉，病日衰已矣。其满三日者，可泄而已。

歧伯回答道，治法在使脏腑之经脉流畅不阻，病必日渐衰微（免疫系统治疗即萌于此），若是病未及三候，可一汗而愈。如满三候病入肠腑中，可用通利法，攻下而愈。

那黄帝问啊，要如何去治它？

岐伯说，“治之各通其藏脉”，我们要治他的脏跟治他的脉——经脉，十二经脉。“病日衰已矣。其未满三日”，三日就是三侯二十一天。在阳上统统可以汗解。满三日进入里的时候，我们可以宣泄，有时利小便，有时候利大便，诸如此类。那这里就定下一个法则，所以在讲《伤寒论》的时候我们就有很多汗法。

歧伯回答，会有余邪遗留体内者，是仍有发热时，却勉强饮食入胃造成的。此因病衰退时，余热因饮食而内藏，饮食之热与其余邪相合，造成发热，这就是遗热之因。

那黄帝问啊，有的人病好了，结果过几天热又回来了。发烧你把他治好了，过几天热又回来，为什么呢？

267 页，岐伯说，会有遗热，这个热会回来的，尾端的热。就是因为“热甚而强食”，在发高烧的时候吃东西，勉强自己吃东西，“故有所遗热。”所以“若此者，皆病已衰而热有所藏，因其谷气相薄，两热相合，故有所遗也。”所以一般来说我们在治疗表症的时候，治病的时候，你告诉他，即使你饿吃一点很清淡的，一些米汤之类。甚至你能不吃就不要吃都没有关系。人七天不吃不会死掉的。那等到病好了再去吃，否则的话你把热退掉了过几天又回来。这时候他想说，“我感冒了嘛，生病了，这时候我应该吃得更多一点。”就造成胃里面热很多。

# 帝曰，善。治遗奈何？

黄帝说，答得好。那像如此反复发热，该如何治疗呢？

歧伯曰，视其虚实，调其逆从，可使必已矣。

歧伯回答，看它的虚实，调理其顺逆之过与不及，必能愈。

# 帝曰，病热当何禁之？

黄帝问，有热病时，须禁忌事项是什么？

歧伯曰，病热少愈，食肉则复，多食则遗。此其禁也。

歧伯上，热病稍愈时候忌食肉类，否则热必复来；又忌多食，会生遗热，这是禁忌事项。

268 页，这就是禁忌。黄帝说，如果有发热病的时候，我们的禁忌是什么？热病，刚开始慢慢恢复的时候，一定要不可以吃肉类的东西，这个肉类的东西不要吃，会造成遗热。这个热会停在里面，没有办法完全的发散出来，“多食则遗”，这个是他的禁忌。所以如果你吃米面谷类，这种东西最好。吃稀饭啊，配一点这个酱瓜啊这种就可以了。配肉松的东西就不好了。要吃一点水煮的青菜这样可以。

# 帝曰，其病两感于寒者，其脉应与其病形何如？

黄帝问，阴阳两感于寒邪时，其脉形与病症是如何呢？

歧伯曰，两感于寒者，病一日则巨阳与少阴倶病，则头痛口干而烦满。二日则阳明与太阴倶病，则腹满身热，不欲食谗言。三日则少阳与厥阴倶病，则耳聋囊缩而厥。水浆不入，不知人，六日死。

歧伯回答，阴阳同时感受风邪时，若一侯七日内，太阳与少阴同时生病，其症状是头痛口干，烦躁腹满状。二候病入阳明与太阴同时受病，其症状是少腹胀满，身体高热，饮食不入，胡言乱语。三候二十一日，邪入少阳与厥阴，二经同时受病，造成耳聋阴囊内缩手足逆冷，食物饮水无法入口，不识亲人，此六日内必死。

黄帝再问啊，“两感于寒者，其脉应与其病形何如？”

岐伯就回答、解释，什么叫做“两感于寒”？就我刚刚说过的，你病刚一开始的时候，这个两感于寒的时候，就是因为前面一个寒症已经进入阴症了嘛。结果进入的时候，你后面还有一个进来，对不对！就变成病人第一个周期看到太阳和少阴并病。我们讲两感于寒就是有阴症有阳症同时出现的时候，这就是两感于寒。少阴和太阳俱病的时候，病人就会有太阳和少阴症两个症同时出现。你看“头痛口干而烦满”；口干烦满是不是少阴症，对不对！头痛是太阳症。你说，“老师这个人太阳症，怎么还有少阴症？”这就是两感于寒。

如果二日，在一个周期，阳明与太阴俱病的时候，病人腹满身热，腹满是太阴症，身热是阳明症，对不对！“不欲食谵言”，就是不想吃东西，话又讲得很多。这个跟那个讲人家谗言，小人在那边讲那个不太一样。就阳明症里面有胡言乱语，讲话就是不经过大脑，已经神昏了嘛。

三日，第三个周期以后呢，如果少阳和厥阴碰在一起，两个俱病的时候，就是少阳也感于寒，厥阴也感于寒。“耳聋囊缩”，耳聋就是少阳的寒，囊缩是厥阴的寒。这个‘厥’就手脚是冰冷的，这个时候“水浆不入，不知人，六日死。”六日，就是六天里面死掉。所以说这个日是讲一个周期，一个候，那有时候就是指一天。

我们有五实和五虚，遇到这种情形的时候，你没有办法处方。没有办法处方的时候，那“老师他这个六日死，对不对！”好，我们就给他算看看准不准，“呀你看！死掉了，真准！”这个我们当医生不能这样子。（笑）那你想想看，如何让他好？对不对！那你说中药的药又不能入啊，这时候你要不要下手？要下手，你可以用针灸啊，想办法去救逆，我们有四逆去救逆。还有你让他下一些米汤，很热的米汤下去，让他能够一吃下胃里面受到热气。同时受到米粥，因为这个米汤是天地之间的精华。为什么稻类很好？因为稻类的东西就按照春生、夏长、秋收、冬藏，因为它这个稻谷本身就按照四季的节气走，所以它是天地之间的精华。

你有没有想过一个问题，我们人……，我希望大家呢，不要很死板的读书。那个好学生学不好中医的，要皮点点。你这样子想，那个稻米做起来是不是一粒粒小小的，你有没有看过那么大一颗的稻米？没有，都是小小一粒的，为什么？像以前人年龄大了到了90岁啊，你牙齿都没了。没有西方的那个植牙的手术。你吃稻米吃下去，你不用咬，吞下去就可以吃呀。所以稻米要做得小小的，有没有道理？真是妙！光是看稻米，你说一颗米，你看到的形，我看到的是神，不一样。所以如果稻米做那么大，这是上帝有问题，（笑）绝对有问题，把它做那么小，你说厉不厉害，真的是很聪明，非常有智慧！

# 第二节 阳明腑热经热、遗热、热病禁忌;暑病、温病

帝曰，五藏已伤，六府不通，荣卫不行，如是之后，三日乃死。何也？

歧伯曰，阳明者，十二经脉之长也。其血气盛，故不知人。三日其气乃尽，故死矣。凡病伤寒而成温者，先夏至日者为病温，后夏至日者为病暑。暑当与汗皆出，勿止。

黄帝问，一旦五脏受损，六腑又无法排泄，气血不通利，如此则病人经过三日便死亡，为什么呢？

歧伯回答，阳明是十二经脉中最首要的，其脉气血过盛，必不识亲人。三日后，胃气已尽竭，故病人必死。

凡病始于冬季伤于寒后成温热病的，在夏日至前发病为温病，在夏至日后为中暑，暑热会与汗同时出，故吾人可用汗法把暑邪自汗出而离开身体。

269 页，黄帝说，“五藏已伤，六府不通，荣卫不行，如是之后，三日乃死”，为什么？这个很惨，你五脏都伤到，六腑又不通，气血又不行，那怎么办？三日，为什么这个三天就死掉了？

岐伯说，阳明者，是胃气。“十二经脉之长”，最大的十二经脉。胃气就是阳明是多气多血的经脉。这个血气太盛的时候，阳明经本来是应该由头上往脚下走，所以阳明经走到脚下的时候，是脚的历兑穴。如果阳明经气逆盛的时候，因为阳明经是多血多气的经络，冲上来的时候会不知人。因为你不能吃东西，五脏又受伤，怎么样？三天的时候，阳明经气最多维持三天，胃气只能维持，那就死掉。

269 页，这里又下了个定义。岐伯说，凡病伤寒而成温者，凡是病伤于寒，冬天伤于寒呢，春天发病，“先夏至日者为病温，后夏至日者为病暑”，这里把温病跟暑病切开来了。所以你如果说，“冬伤于寒，老师，这个人到春天的时候——温病！”不一定的，是以夏至日为主，夏至日之前得到的温热病，那是属于冬天伤于寒是来自寒的。夏至以后得到的温病跟冬寒没有关系，是中暑天气太热。那暑病怎么解呢？汗解，当汗者解。这都是替汗法下了注解。那你不要去止它。暑病可呢……，我们所谓汗，汗是阳。那汗出了阳失的时候，我们用汗解，当我们阳到极的时候，阴自己会回头。所以我们处方，伤寒家经方跟温病派处方不一样。温病一看，滋阴滋阴滋阴，滋阴对我们来说就是会有余热，余热在里面。

那肉类的都是阴，你看肉类。你吃肥肉，肥肉是阳，瘦肉是阴嘛。吃肉类都是瘦肉，你吃肥肉都是阳，所以肥肉包瘦肉，阳包阴嘛。你如果说你去滋阴它，它余热在里面，刚开始会很好啊，烧退了，可是过几天又来了。那你没有叫病人停止吃肉，它还是会来的。那我们处方的时候，我们会用一些发散的药，一发散的时候，它阴液，它自己会回头，所以我们开处方的时候，除了发表的药，我们会同时放一些滋润的药在里面。同时告诉病人，一些肉类不能吃，只能吃些谷类的东西，一些蔬菜类，这样就可以了。
